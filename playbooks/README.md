# MeetingVA AI Playbooks

These playbooks define repeatable operating workflows for Walter Labs AI and MeetingVA AI.

## Files

- `RELEASE_PLAYBOOK.md`: prepare, validate, document, commit, push, and smoke test a release.
- `DEPLOYMENT_PLAYBOOK.md`: deploy through Supabase, Render, and Vercel.
- `FEATURE_DEVELOPMENT_PLAYBOOK.md`: plan and implement new features safely.
- `BUG_FIX_PLAYBOOK.md`: triage, reproduce, fix, validate, and document defects.
- `MARKETING_PLAYBOOK.md`: run founder-led marketing and launch loops.
- `ONBOARDING_PLAYBOOK.md`: guide early customers to first useful processed meeting.
- `DISASTER_RECOVERY_PLAYBOOK.md`: respond to production, data, deployment, queue, and secret incidents.

## Update Rule

When a workflow changes, update its playbook before relying on memory. If the workflow affects release readiness or blockers, update `../docs/PROJECT_STATUS.md` too.
