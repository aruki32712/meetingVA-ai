# Customer Onboarding Playbook

## Purpose

Use this playbook to help early users reach their first useful processed meeting.

## Before The Call

- Confirm the user has a browser with microphone support.
- Use a test or low-risk meeting first.
- Avoid sensitive customer data during early beta if security review is incomplete.

## Onboarding Flow

1. Create an account.
2. Open the dashboard.
3. Capture a short meeting.
4. Save the recording.
5. Open the meeting detail page.
6. Generate transcript.
7. Generate analysis.
8. Review summary, action items, decisions, questions, and speakers.
9. Ask what was useful, missing, confusing, or wrong.

## Success Criteria

- User completes one useful processed meeting.
- User understands where to find meeting history.
- User identifies one real workflow where MeetingVA AI saves time.
- User agrees to process another meeting within seven days.

## Feedback Questions

- What job did you hope this would do?
- Where did you hesitate?
- Which output would you trust enough to use?
- What would make this worth paying for?
- What integration or export matters most?
